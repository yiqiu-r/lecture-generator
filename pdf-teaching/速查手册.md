## 0. 本机编译（TeX Live 2026，已装好）

安装位置：`<你的 TeX Live 根目录>`（约 672 MB，装在 `.workbuddy\binaries` 下，**没有改动系统 PATH**，与系统里其他软件互不影响）

**最省事的方式**：双击本目录的 `build.bat` —— 会把该文件夹里所有 `.tex` 各编译两遍，PDF 直接落在同目录；也可以 `build.bat 文件名.tex` 只编一个。

手动调用（等价）：
```bat
:: 编译（XeLaTeX，需要跑两遍目录才有页码）
%TEXLIVE_ROOT%\bin\windows\xelatex.exe -interaction=nonstopmode 你的文件.tex
%TEXLIVE_ROOT%\bin\windows\xelatex.exe -interaction=nonstopmode 你的文件.tex
```

- 第一遍生成 `.aux/.toc`，第二遍目录页码才正确。
- 插了 TikZ 图时第三遍更稳。
- **缺包时临时补装**（走清华源，几秒钟）：
  ```bat
  %TEXLIVE_ROOT%\bin\windows\tlmgr.bat install 包名
  ```
  包名可写多个，如 `tlmgr.bat install tikz-cd algorithm2e`。

安装时基础方案用的是 `scheme-small`（约 570MB），另外补装了模板依赖共 20 多个：`tcolorbox pgfplots tikz-3dplot tikzfill pdfcol pict2e newunicodechar esint diagbox makecell multirow needspace listingsutf8 docmute hypdoc soul varwidth xstring ifmtarg adjustbox collectbox changepage pdftexcmds uniquecounter palatino mathpazo`。
（`bm` 归在 `tools` 里、`subcaption` 归在 `caption` 里，所以不用单独装；`palatino` 提供 Palatino 的 TFM，`mathpazo` 提供它的数学字体，缺任一个都会报 "Metric (TFM) file not found"。）
补完后 **模板与骨架都实测编译通过**（18 页 / 17 条书签 / 无误）。

命令行助手：`<你的 TeX Live 安装目录>\build_tex.py`，用法 `python build_tex.py 文件.tex`，供自动化流程调用。

### 字体：模板已做自动回退

原模板写死 `Noto Serif CJK SC`，但 **Noto CJK 不在 TeX Live 里**，本机没装就会直接编译失败。改好的模板加了 `\IfFontExistsTF` 判断：

- **Overleaf 上**（有 Noto）→ 照旧用 Noto Serif CJK SC / Noto Sans CJK SC，效果和原来完全一样；
- **本机**（没 Noto）→ 自动退回 TeX Live 自带的 **FandolSong / FandolHei**，能正常编译出中文。

`\kaishu` / `\heavykaishu`（楷体）用的是 TeX Live 自带的 FandolKai，两边都可用。

实测本机产出的 PDF 内嵌字体是 `FandolSong-Regular` + `FandolKai-Regular` + `TeXGyrePagella` + `PazoMath` —— 回退分支确实生效。
**想让本机也用 Noto**：把 Noto Serif / Noto Sans CJK SC 装进系统字体即可，模板会自动改用，不用改代码。

## 1. 环境速查

统一写法：`\begin{环境}[可选标题]` … `\end{环境}`；可选标题会排成「定理 1.3（可选标题）」。

### 逻辑类（玫红）

| 环境 | 中文名 |
|---|---|
| `theorem` | 定理 |
| `lemma` | 引理 |
| `proposition` | 命题 |
| `corollary` | 推论 |
| `property` | 性质 |

### 定义类（橙）

| 环境 | 中文名 |
|---|---|
| `definition` | 定义 |
| `axiom` | 公理 |

### 例题类（钢蓝）

| 环境 | 中文名 | 说明 |
|---|---|---|
| `example` | 例题 | **只含题面**，解答写盒外 |
| `longexample` | 例题 | 可跨页，支持 `\tcblower` 题解分栏 |
| `exercise` | 练习 | |
| `realexam` | 真题 | 方括号填**出处**：`\begin{realexam}[2019 数学一]`；**不编号** |
| `longrealexam` | 真题 | 可跨页版 |

### 解释类（紫）· 本版新增

| 环境 | 中文名 | 说明 |
|---|---|---|
| `explanation` | 解释 | 放白话解读、动机、"为什么这样想" |
| `longexplanation` | 解释 | 可跨页，支持 `\tcblower` |

### 结论类（青）· 本版新增

| 环境 | 中文名 |
|---|---|
| `conclusion` | 结论 |

### 非盒子环境

| 环境 | 效果 |
|---|---|
| `note` | `注：` + 绿色粗体引导，无边框 |
| `proof` | `证明：` + 玫红引导，结尾自动补玫红实心方块 |

> `proof` 支持可选标题：`\begin{proof}[第二步]` 会排成「证明（第二步）：」。
> 原版不支持，会报错；本版已修补。

### 题型辅助命令

| 命令 | 效果 |
|---|---|

## 2. 编号机制（最容易搞错的地方）

模板**只用一个 `theorem` 计数器**，所有带编号的盒子共享它：

```latex
\newcounter{theorem}[chapter]                        % 按章重置
\renewcommand{\thetheorem}{\thechapter.\arabic{theorem}}
```

- 定理 / 引理 / 命题 / 推论 / 性质 / 定义 / 公理 / 例题 / 练习 / **解释 / 结论** 全部走 `\refstepcounter{theorem}`。
- **结果**：定义 1.1 → 定理 1.2 → 解释 1.3 → 定义 1.4 → 例题 1.5 …… **连成一串编号**（中文教材常见做法，属有意设计）。
- `realexam` / `longrealexam` **不编号**。
- 公式编号走 `\numberwithin{equation}{chapter}` → (1.1)、(1.2)，按章重置。
- `\newcounter{definition}`、`\newcounter{example}` 与 `\thedefinition`、`\theexample` 是**上游遗留的死代码**，无人使用。
  **想做「定义、定理各自独立编号」**：把 `defBox` 的 `before title` 与 `title` 改成 `definition` / `\thedefinition` 即可，其余同理。

## 4. 自定义命令与全局改动

### 自己定义的

| 命令 | 含义 |
|---|---|
| `\R` | `\mathbb{R}` |
| `\sep` | 「 · 」带间距分隔符 |
| `\ge` `\geq` `\le` `\leq` | 被改成 `\geqslant` / `\leqslant`（**全局**） |
| `\fillin` `\selectbracket` | 见 §1 |
| `\LectureNotesTitle` `\AuthorInfo` | 讲义标题/作者，页眉取这两个 |
| `\MakeTitlePage` | 封面宏 |
| `\kaishu` `\heavykaishu` | 楷体 / 伪粗楷体 |

### 被悄悄改掉的（重要）

```latex
\renewcommand{\lim}{\displaystyle\oldlim}     % \int \iint \iiint \oint \oiint \sum 同理
```
**行内公式里的 `\lim \int \sum` 也强制行间样式**（上下限悬顶、积分号变大），会明显撑高行距——这是刻意的讲义风。

```latex
\renewcommand{\dfrac}[2]{...}   % 加隐形 \vrule 撑开上下留白
```
所以**优先用 `\dfrac` 而不是 `\frac`**，分式套分式时尤其。

### 排版微调 Hook（LaTeX 2020+）

`\AddToHook{env/xxx/before}{...}` 给 `pmatrix` / `bmatrix` / `vmatrix` / `dcases` / `enumerate` 加行距与上下留白，防止矩阵和列表贴住正文。旧版 TeX Live（<2020）会报错。

## 5. 中文标点会被自动替换

```latex
\newunicodechar{。}{.\ \ignorespaces}   % ，：；？！（） 同理，共 8 条
```

- 你**照常打中文标点**，排出来是「西文标点 + 一点间距」，这是模板刻意的中西混排风格。
- `\ignorespaces` **会吃掉标点后面紧跟的空格**，想留空得显式写 `\quad` 或 `\,`。
- 引号「」、顿号、书名号《》**不受影响**。
- 想用常规中文排版（全角标点），把这 8 行删掉。

## 9. 小坑清单

1. **必须 XeLaTeX**，pdfLaTeX 会死在字体设置上。
2. 中文字体已做自动回退（§0），没装 Noto 也能编译。
3. `realexam` 的参数是**出处**不是标题，且**不编号**。
4. `example` 盒子**不含解答**，解答写盒外；要题解同框用 `longexample` + `\tcblower`。
5. **长内容一律用 `long*` 系列**（带 `breakable`），否则跨页会被截断。
6. 所有盒子**共享一个编号**（§2）。
7. 行内 `\lim \int \sum` 被强制 display 样式。
8. 中文标点被自动替换，标点后的空格会被吃掉（§5）。
9. **`\begin{proof}[标题]` 原版会报错**，本版已修补。
10. 目录页码需要编译**两遍**。
11. 想给目录加可点击链接和 PDF 书签，需要 `hyperref` —— **本版已内置**。
12. `fontset=none` 意味着 ctex 不提供中文字体，字体那几行不能删。

## 11. 与既有工作的衔接

- 这套「定义/定理/解释/结论分色盒子 + 按章编号 + 楷体章标题」正好对上 Kuo《随机积分》讲义要求的四种分色框，可以直接当正式排版底子。
- 你的术语约定（**域流** / **下鞅** / **适应于域流** / **自然域流**）需要在正文里手动统一，模板不干预用词。
- 收敛类型（逐点、一致、依概率、L¹、L²、a.s.、依分布）建议统一用 `\text{}` 写出全称，别混用缩略语。
- 目录/书签已可用；PDF 交付时留意 `hyperref` 会给内部链接上色（当前用 LogicColor 等主题色，可在 `\hypersetup` 里改 `linkcolor`）。
